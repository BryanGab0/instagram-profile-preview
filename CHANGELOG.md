# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project
uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-24

### Added

- iPhone mockup with a faithful replica of an Instagram profile as seen by visitors on iOS.
- Profile editor: avatar, username, name, bio with highlighted mentions and hashtags, link,
  stats, verified badge and story ring.
- Highlights with custom covers.
- Post grid in the 3:4 format with multi-image upload and drag-and-drop reordering.
- Light and dark Instagram themes and Portuguese and English preview text.
- Site dark mode that follows the OS until the user picks a theme.
- Profile and preferences saved in the browser, with a button to start over.
